# 方寸巧拼（Tangram）

一款微信小游戏 + 网页预览版的拼图游戏：**四巧板 120 关 + 七巧板 18 关**，纯 Canvas 绘制、零图片依赖的 UI、Web Audio 现场合成音乐。

> 原名《四巧·七巧》，v0.6 起改名为「方寸巧拼」。

## 玩法

- **四巧板**：4 块板拼指定剪影，120 关。
- **七巧板**：标准七巧板 7 块，18 关，分「几何·入门（10 关）/ 字母·七巧（A E F L N P V Y 8 关）」两章。
- 拖动摆放、拖拽或点手柄旋转（吸附 45°）、双击板件翻转、顶点/边/网格三层吸附。
- 三档提示（指位置 → 指板件 → 看全图），每档都要付：查找道具 / 巧币 / 看视频三选一，用提示星级封顶 ★★☆。
- 倒计时 + 3 颗生命，时间归零可看广告或花巧币复活；巧币/体力、在线奖励（6 档）、邀请有礼、皮肤。

## 目录结构

```
js/                  核心逻辑（三端同源，唯一真源）
  config.js          所有可调参数与配色（改数值只改这里）
  geom.js            几何工具与缓动
  judge.js           栅格覆盖率判定（位掩码，支持 4/7 块）
  levels.js          关卡数据（四巧 120 + 七巧 18）
  core.js            渲染 / 交互 / 状态机
preview/             网页预览版（双击 index.html 即玩）
miniprogram/         微信小游戏工程（用微信开发者工具导入这一层）
tools/               构建、验收、截图、音频探针
docs/shots/          各版本验收截图
assets/              图片与音频素材
animation/ art-src/ audio-src/   动效演示、素材源文件
```

## 运行

**网页版**：直接双击 `preview/index.html`（无需服务器、无外网请求）。

**微信小游戏**：微信开发者工具 → 导入项目 → 选 `miniprogram/` 目录（`project.config.json` 里已配好 `compileType: "game"`）。

## 开发约定

- `js/` 是唯一真源，`preview/js/` 与 `miniprogram/js/` 由 `node tools/sync.js` 同步，**不要手改副本**。
- 改完必须跑：`node tools/sync.js && node tools/verify_v18.js && node tools/verify_v17.js && node tools/verify_v16.js && node tools/verify_v15.js && node tools/verify_v14.js && node tools/verify_v11.js && node tools/verify_audio.js && node tools/smoke.js`。
- 关卡数据变更需跑 `verify_levels.js` / `verify_tangram7.js` / `verify_tangram7_geometry.js`。
- 截图验收：`node tools/shot_v11.js`（提示/对局页）、`node tools/shot_v14.js`（设置页资料态/榜单头像）、`node tools/shot_v15.js`（在线奖励页/主页气泡）、`node tools/shot_v16.js`（主页无任务/查找道具面板/邀请有礼）、`node tools/shot_v17.js`（对局页/复活/结算的余量胶囊）、`node tools/shot_v18.js`（连胜榜/好友榜/榜单失败态）。
- 玩家资料：`miniprogram/js/wxprofile.js`（只有小程序端有）；`core` 只认 `env.profile`，浏览器预览自动降级。
- 音频链路：`node tools/verify_audio.js`（wx 桩真跑 game.js）+ `tools/audio_probe.html`（真实浏览器跑预览端 `<audio>`）。
- 换关卡 BGM：把 mp3 丢进 `audio/`，按 `1_/2_/3_/4_` 前缀命名，跑 `cd tools/audiokit && node build.mjs`（90s/48kbps 单声道，4 首约 2.0MB）。
- 主页 BGM 不用文件：`AUDIO.pad` 里的和弦表 + `AUDIO.bgm.home=''` 决定，改和弦/速度只动配置。
