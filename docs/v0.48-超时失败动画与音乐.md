## 一、失败音乐

### 乐句

两端 `game.js` 的 `buildSfxSynth()` 新增 `sfx_timeup`：

- **A 小调下行**：A4(440) → F4(349.23) → D4(293.66) → A3(220)，每音错开 190ms；
- 尾部补一个 A2(110) 的木质闷音收句，总长约 **1.55 秒**；
- 钟琴分音起音、木质低音收尾 —— 和 `sfx_win` 的 C 大调上行琶音构成情绪对照。

它和 `sfx_win` 一样属于**情绪表达**而非材质反馈：任何音效风格下都直接走合成，不读 wav 素材、不随木质/铃音切换。`config.AUDIO.sfxGain` 加 `sfx_timeup: 0.85`，`files` 里故意不登记文件（纯合成零资源）。

### 让背景安静：`audio.halt()`

旧的 `failLevel()` 只播一个 0.26 秒的 `sfx_tap`（其实是"拼接重叠"提示音），关卡 BGM 继续放，两者混在一起。

现在失败时：

```js
if (env.audio.halt) env.audio.halt();
env.audio.play('sfx_timeup');
```

`halt()` 停掉 mp3 与主页合成曲，但**不改 `bgmScene`** —— 复活时 `doRevive()` 原本就会调 `setLevelScene()`，关卡曲自然恢复；放弃时 `go()` 也会切回主页曲。不用 `setScene('home')` 是因为那会把主页曲放起来，比关卡曲还吵。

两端 `game.js` 对称实现，`bgmInfo()` 可观察 halt 效果。

## 二、失败动画

### 时间轴（配置在 `config.FAIL_ANIM`）

| 时刻 | 效果 |
|---|---|
| 0–320ms | 全屏红闪，alpha 0.34 → 0 |
| 0–460ms | 复活卡片从下方 48px 滑入，缩放 0.94 → 1（`easeOutCubic`） |
| 0–640ms | 大红心 `easeOutBack` 弹出 + 前 700ms 轻微心跳 |
| 280–900ms | 心形裂痕淡入淡出（两条白色折线） |
| 0–1300ms | 「时间到！」红色横幅从上方 90px 砸下、倾斜回正，950ms 起淡出 |

横幅画在卡片**上方外侧**（`cy − 490`），不遮挡标题胶囊，也不影响任何热区。

### 两条硬约束

1. **变换全包在 `ctx.save()/restore()` 里** —— 动画结束后版面与静态版逐像素相同（`verify_v048` 断言 1500ms 后横幅/红闪全部退场、按钮文案齐全）。
2. **动画期间不注册热区** —— 卡片还在缩小时按钮位置与视觉不一致，`hitOK = !anim || enter >= 1` 避免错位点击。

`state.failT` 只在 `overlay === 'fail'` 时推进，关掉弹窗即停；下次失败由 `failLevel()` 归零。`state.reduceMotion` 为真直接走静态版（低配机 / 减少动态效果）。

### 实现踩坑

- **横幅曾一度完全不显示**：把横幅块移到卡片绘制之前时，`var cy = DH()/2` 的声明留在了横幅块之后。JS 变量提升使 `cy` 为 `undefined`，`byy = NaN`，`translate` 把横幅送到了画布外。修法是把声明前移。
- **截图帧不确定**：harness 靠 rAF 渲染，`--virtual-time-budget` 下帧数不固定，同一 `failT=0` 有时拍到红闪、有时拍到静态版。给 harness 加 `&freezeFail=1`，用 `Object.defineProperty` 把 `S.failT` 钉成常量，时间线截图才可复现。
