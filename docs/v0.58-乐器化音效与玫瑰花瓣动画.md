# v0.58 乐器化音效 + 玫瑰花瓣/蝴蝶动画

> 两条反馈：① 通关彩带要放慢、要逼真、要「由少量变大量」，原来的程序化鲜花换成逼真的玫瑰花瓣 + 蝴蝶；
> ② 皮肤里的八种音效要逼真，贴合每种乐器本身的音色。

---

## 一、彩带：从「弹道炸开」到「纸片飘落」

### v0.55 为什么看起来假

| 问题 | 数值 |
|---|---|
| 重力 1750，中心到屏幕底部 1.6s 就走完 | 像石头，不像纸 |
| 一次性生成 240 片 | 没有「起势」，炸完就开始掉 |
| 平面矩形 + `|cos|` 收缩 | 只有「变窄」，没有正反面受光差别 |

### v0.58 的三处改动

**1）空气阻力 + 终端速度**

```
x(t) = x0 + vx·(1−e^{−kt})/k + A·sin(ωt+φ)
y(t) = y0 + (vy−vt)·(1−e^{−kt})/k + vt·t
```

取 `k = 1.35 /s`、`vt = 300 px/s`。初速在 0.3 秒内被空气吃掉，之后匀速飘落 ——
从中心掉到屏幕底部要 **3.7s**（原来 1.6s），同样的 8.6s 生命周期里它在屏幕上多待一倍多。

**2）四波喷射（由少到多）**

| 波次 | 触发 | 片数 | 初速 |
|---|---|---|---|
| 1 | 0ms | 14 | 290 |
| 2 | 380ms | 30 | 340 |
| 3 | 820ms | 48 | 390 |
| 4 | 1340ms | 64 | 440 |

第一波几乎是垂直向上的「一小把」，后面逐步张开成扇形。前 1.3 秒能明显看到
「先冒一点 → 越来越多」的过程，而不是一瞬间糊满屏。

**3）纸感**

- 每片有独立的 `flip` 相位（3.4~8.4 rad/s），横向缩放 = `|cos(flip)|`；
- 受光 `lit = (0.70+0.30·|cos|) × (cos<0 ? 0.86 : 1)` —— 背面比正面暗 14%；
- 沿一侧长边再压一条 +16% 的折痕亮带；
- 侧立（`|cos| < 0.30`）时补一条白色纸边高光，避免「片状物凭空消失」。

低帧率下四波按 55% 抽样（共 86 片），`reduceMotion` 时整套不画。

## 二、鲜花 → 玫瑰花瓣 + 蝴蝶

原实现是 `drawFlower`：七瓣放射 + 花心圆点 + 六朵卫星花。程序化痕迹重，
用户要求换成真实感更强的玫瑰花瓣和蝴蝶。

### 玫瑰花瓣（`drawRosePetal`）

三层画法：

1. **主体**：贝塞尔轮廓，顶端做成「左波峰 → 中间凹口 → 右波峰」——
   玫瑰花瓣的辨识点就在这个凹口，平滑的水滴形会看成柳叶；
2. **内卷暗面**：贴着左侧的一道月牙，压暗 26%（不是从中间劈开 —— 那是叶脉不是卷边）；
3. **边缘高光**：顶端一条 26% 提亮的细弧，做绒面质感。

飘落运动同样是阻力模型（`k=1.6`、`vt=78px/s`），叠加 `sin` 左右轻摆；
`flip` 控制 3D 翻面，且**越侧立越透明**（`alpha × 0.74~1.0`）——
真实薄花瓣侧过来本来就快看不见，不这样处理会变成一道红色划痕。

通关瞬间喷 28 片（低帧率 16），按序号均匀分角再随机扰动，
避免纯随机时半屏挤成一团。

### 蝴蝶（`drawButterfly`）

- 前翅 + 后翅各用两段贝塞尔，深色翅缘，翅面带一枚翅斑；
- 身体是椭圆，两根触角用二次曲线；
- 翅膀开合 = `scaleX(0.24 + 0.76·flap)`，`flap` 走 6~10Hz 正弦；
- 轨迹不是直线：`x = x0 + sin(t·fx+φ)·ax`，`y = y0 − rise + sin(t·fy+1.7φ)·ay`，
  再加一个缓慢的 `rot` 摆动；
- 配色四套：帝王斑蝶（橙）/ 大蓝闪蝶（蓝）/ 白粉蝶（白）/ 黄粉蝶（黄）。

通关瞬间出 5 只（低帧率 3），延迟 150ms 起、每只间隔 150ms。

### 结算页的余韵

`drawWinStream` 复用原来的确定性排程（同一关每次落点一致、只在卡片上下留白带），
把「小花」换成「花瓣」，并且**每 9 个粒子里放 1 只蝴蝶** ——
蝴蝶比花瓣抓眼，密度再高就乱了。花瓣尺寸 22~36px，蝴蝶落在同一区间内。

## 三、音效：八种风格 = 八件乐器

### v0.31 的问题

引擎本身不差（非谐分音 + 噪声瞬态），但八种风格跑的是**同一套算法**，
只改 `pitch` / `decay` 两个倍数。结果就是「同一件乐器调了个音」，
木琴听起来像欠亮的铃，钟听起来像拖长的木鱼。

### v0.58 的引擎改动

1. **琴体低通 + 共振 Q**：每次敲击挂一个 `lowpass`（截止 = `f0 × lpMul`），
   把所有分音收成一件乐器。没有这一步，分音各自干响，耳朵听到的就是「几个正弦叠加」。
2. **拍频对**：`beat` 音分的前 3 个主分音各多发一枚失谐副本（振幅 55%），
   产生 2~6Hz 的拍频 —— 这是钟和风铃「嗡——」晃动的来源。
3. **余音** `ring`：寿命 = `dur × ring`，且不超过自身衰减的 5.5 倍。
   钟 2.4、风铃 3.2，才能真的响起来；木质仍锁 1.0，短促。
4. **低频冲击** `thump`：0.5×f0 起振、90ms 内滑到 0.3×f0 的正弦。
   木质和马林巴的「落地感」全靠这一下，纯高频分音没有重量。
5. **滤波器包络** `fenv`：合成器的截止从 `26×f0` 指数扫到 `6×f0`（130ms），
   经典减法合成的「哇」。
6. **振幅归一** `norm`：钟的分音多了（8 个），总振幅要压到 0.5，避免比其它风格响一截。

### 八件乐器的分音表

| 风格 | 模态 | 关键参数 |
|---|---|---|
| 木质（梆子） | 非谐 1 / 2.42 / 4.11 / 6.8 + 半频 0.5 | 极短（52ms）、强瞬态 0.62、下滑 4.5% |
| 铃铛（青铜钟） | hum .5 / prime 1 / tierce 1.19 / quint 1.51 / nominal 2.0 + 2.5/3.0/4.07 | 拍频 7 音分、余音 ×2.4 |
| 水滴 | 1 / 1.62 / 2.9，**上行滑音 +34%** | 极短 120ms、水花噪声 |
| 复古（8-bit） | 方波 1 / 2 / 3，下滑 16% | 极短 100ms |
| 风铃（铝管） | 极端非谐 1 / 2.76 / 5.40 / 8.93 / 13.3 | 拍频 4 音分、余音 ×3.2 |
| 木琴（马林巴） | **1 : 4 : 10** 调音 + 16.2 | 槌头噪声偏软、轻微下滑 |
| 泡泡 | 1 / 2.24，上行滑音 +52% | 更短更低的「啵」 |
| 合成器 | 锯齿 1 / 2 / 3 | 低通 Q=6 + 截止扫频 |

> 马林巴的 `1:4:10` 不是随手写的：琴条被调音成基频、四倍频、十倍频三模态，
> 其中四倍频决定「木」的音色。方波留给复古（8-bit 街机）是刻意的，
> `verify_v20` 的「不用方波」断言因此改成「默认 7 种不用方波、只有复古用」。

### 通关 / 失败音

- 通关：C5–E5–G5–C6 四个钟音，每个 `dur` 从 1.1 收到 0.42（余音交给 `ring` 控制，
  四音不会糊成一片），尾部补一个 C4 低八度。
- 失败：仍是 168Hz 的木质闷音，不随风格变成清脆铃音（语义必须稳定）。

## 四、验收

新增 `tools/verify_v058.js`：**不读源码猜，而是把合成引擎整段抽出来用假
AudioContext 真跑**。共 25 项：

- A1 两端 `SFX_MAT` 完全一致（防止只改一端）
- A2 八种风格都排了振子 + 挂了琴体滤波，峰值 < 1.0（不削波）
- A3 分音比符合乐器模态（钟的 tierce、马林巴的 4/10、风铃的 2.76…）
- A4 钟/风铃各有 3 枚失谐副本（拍频）
- A5 合成器的截止扫频是「高 → 低」两段
- A6 木质/马林巴有 0.5×f0 的下滑冲击
- A7 通关音四音 + 低八度收尾；失败音仍是木质
- B1 彩带四波递增（14→30→48→64）、终端速度 < 400、总时长 ≥ 8s、
     源码里已经没有旧弹道公式 `0.5·GR·t²`
- B2 花瓣/蝴蝶函数到位，旧 `drawFlower` / `flowerState` 已删除，
     结算粒子含 `bfly`

顺带更新 `verify_v20.js`（方波断言按风格拆开、木质半频数值跟随新表），
其余 31 个脚本全量回归 **exit 0**。

## 五、取舍

- **性能**：彩带满配 156 片（低帧率 86），每片 2 次 `fillRect` + 偶尔 1 次 `stroke`；
  花瓣 28 + 蝴蝶 5，每片 3 次填充。实测 750×1717 的截图环境无压力，
  低帧率档位已按 55% / 16 / 3 自动降级。
- **结算页遮挡**：彩带画在最上层（这是冲击力的来源），4~5 秒后已落到卡片下半部，
  不挡「下一关」按钮；真正的文字区只在前 2 秒有少量纸片掠过。
- **钟的余音上限**：`life` 封顶 2.6s。风铃 `ring` 3.2 但 `dur` 只有 0.48s，
  实际约 1.5s —— 再长会和下一声操作音叠在一起变糊。
