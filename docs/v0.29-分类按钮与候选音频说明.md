|---|---|---|

| `试听.html` | 交互式试听页：单曲播放 + 混音滑块 + 4 种场景预设 | 决策用 |
| `gen_audio.py` | 纯标准库合成脚本（可改参数重新生成） | 复现/调整 |

### 怎么听
双击 `audio-lab/试听.html`（浏览器打开）：
- **① 候选曲目**：4 个播放器，点 ▶ 直接听。
- **② 动态混音演示**：点「主页平静 / 对局专注 / 倒计时紧张 / 通关」，
  或拖 6 条声部滑块，听各声部平滑淡入淡出——这就是"动态混音"的实际效果。
- 演示要点：切「倒计时紧张」时鼓点+主旋律淡出、紧张脉冲淡入；切「通关」再平滑切回。

### 音频质量自检
全部 RMS 0.09~0.25、峰值 0.62~0.90，无静音、无削波。

### 重要：本版音频**尚未接入游戏**
按你的要求"做些音频出来我看要不要替换"，这批是**无损 WAV 试听样片**，体积约 7MB，
不适合直接进小程序包。你听完拍板后，我会：
1. 挑中的曲目转成 **48kbps 单声道 mp3**（与现有素材一致），
2. 接入 `config.AUDIO` + 两端 `game.js` 的音频层，
3. 用状态驱动动态混音（剩余时间 / 弹窗 / 通关 → 各声部音量），
4. 跑音频验收 + 重测主包体积（目标仍 < 4MB）。
