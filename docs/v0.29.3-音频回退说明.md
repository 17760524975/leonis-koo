# v0.29.3 · 音频回退说明

## 一、背景

v0.29.2 把游戏 BGM 从「主页合成和弦 + 4 首关卡真人曲」换成了
3 首新曲与「巧思时刻」5+1 路动态混音，并替换了胜利音、新增了拼接失败音。
用户试玩后反馈：**整体听感与体验不如上一版**，要求把音效这块的改动还原到上一个版本。

经确认，还原范围如下：

- **回退**：BGM 曲目、动态混音、紧张层、新版胜利音 —— 全部回到 v0.29（commit `56cf7fd`）的链路。
- **保留**：v0.29.2 新增的「拼接失败」音效（用户明确要求留着）。
- **不动**：分类按钮（图案 + 华文彩云汉字）、HUD 左上角回位、皮肤 / 背景特效 / 板件 / 音效风格等所有非音效改动。

基线来源为 GitHub `tangram` 分支的 `56cf7fd`（v0.29），按文件逐一取回音频相关实现，
而非整体回滚提交，因此 v0.29.1 / v0.29.2 的界面改动没有丢失。

## 二、回退后的音频链路（与 v0.29 一致）

| 场景 | 播放内容 | 实现 |
| --- | --- | --- |
| 主页 / 关卡列表 | 8 小节合成轻音乐「暖阳」 | 纯 WebAudio 振荡器，`AUDIO.home` 谱表驱动，`bgm.home = ''` 不引用 mp3 |
| 对局 | 4 首真人 BGM，一关一首、每 5 关换下一首 | `bgm_lv1~4.mp3`，预载 4 个 InnerAudioContext / Audio 元素，切曲复用实例 |
| 通关 | 旧版三音号角（523/659/784/1046Hz） | `play('sfx_win')` 强制走合成，与鲜花动效 242ms 顶点对齐 |
| 交互音效 | 8 种 `SFX_STYLES` 风格 | 木质走 wav 采样，其余风格走 `buildSfxSynth()` 合成 |
| **拼接失败（保留）** | 低沉短促「没吸上」 | `sfx_fail.wav` / 合成兜底，仅在板件真实重叠时播放 |

响度对齐表 `AUDIO.trim` 恢复为旧版实测值
（`home 1.70 / lv1 1.53 / lv2 1.66 / lv3 0.65 / lv4 0.52`），
四首关卡曲之间不会再出现忽大忽小。

## 三、具体改动清单

### 源码
- `js/config.js`
  - `version` → `v0.29.3`。
  - `BGM` 场景名恢复为「主页·暖阳 / 关卡 1~4」原曲名。
  - `AUDIO.files` 恢复 `sfx_win: 'sfx_win.mp3'`，删除 `sfx_win_fanfare`；**保留** `sfx_fail: 'sfx_fail.wav'`。
  - `AUDIO.bgm` 恢复 `home: ''` + `lv: ['bgm_lv1.mp3' … 'bgm_lv4.mp3']`。
  - 删除整段 `AUDIO.mix`（stems / presets / fadeMs / tenseAt）。
  - `AUDIO.trim`、`AUDIO.sfxGain` 恢复旧值，`sfxGain` 保留 `sfx_fail: 0.55`（比成功吸附音 1.00 轻）。
  - HUD 的 `y0=20 / rightAnchor=false / topShift=8` 保持不变。
- `js/core.js`
  - 移除 `setPage()`、`setMix('calm'/'play'/'win'/'tense')` 四处调用，回到只调 `setScene()`。
  - **保留**重叠判定里的 `env.audio.play('sfx_fail')`。
  - 分类按钮 `setBadge/setEntryLabel`、HUD 左锚定绘制保持不变。
- `preview/js/game.js`、`miniprogram/game.js`
  - 整体回退到 v0.29 的 BGM / SFX 链路（主页合成和弦、4 首 mp3 元素池、旧胜利音、`bgmInfo()`）。
  - 在 `buildSfxSynth()` 里补回 `sfx_fail` 合成函数，使非木质风格也有同款失败音兜底。
  - 播放链路本身是通用的：`AUDIO.files` 里有 `sfx_fail` 就会自动加载 buffer / 元素池，
    `playSfx()` 无需为它加特例。

### 资源
- 恢复：`bgm_lv1~4.mp3`、`sfx_win.mp3`（两端 `assets/audio/` 各一份，来自 v0.29 基线）。
- 删除：`bgm_dawn / bgm_starlit / bgm_flow`、`layer_tension`、`sfx_win_fanfare`、
  `stem_flow_{pad,arp,bass,perc,lead}`。
- 保留：`sfx_fail.wav`、`sfx_pick / sfx_snap / sfx_tap.wav`。
- `audio-lab/` 的候选 WAV 样片与 `试听.html` **保留**作试听资料，不进游戏包；
  `tools/audiokit/build_lab.mjs` 转码工具同样保留，方便以后重新评估。
- 主包约 3.2MB，仍低于 4MB 限制。

### 验收
- `tools/verify_audio.js`、`verify_v06.js`、`verify_v11.js` 回退到旧链路断言版本。
- `verify_audio.js` 新增第 12 节，专门校验「回退后仍保留失败音效」：
  配置注册、响度低于吸附音、两端资源一致、两端合成兜底、`core.js` 重叠时确实调用。
- `verify_v07 / v17 / v20 / verify_levels` 等脚本保持当前版本（HUD 与工具修复不回退）。

## 四、验收结果

- 三端同步（`tools/sync.js`）：`config / core / geom / judge / levels` 五模块哈希一致。
- 语法检查：全部通过。
- `smoke.js` 与全部 25 个 `verify_*.js`：**26/26 全绿，0 失败**。
- 浏览器截图：主页 / 对局页正常渲染，无 JS 报错。
