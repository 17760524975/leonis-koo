## 1. 价格配置（唯一事实来源）

价格直接写在 `config.js` 的条目里，逻辑层不另存一份价格表，改价只改这一处：

```js
BG_FX: {
  stars:  { name: '星夜流萤', price: 150 },
  petals: { name: '花瓣飘落', price: 150 },
  snow:   { name: '初雪纷飞', price: 150 },
  // 其余 7 套不带 price → 免费
}
PIECE_STYLES: {
  classic/candy/wood            // 第一行 3 套：免费
  neon/pastel/crystal/metal/jade/glow: price: 100   // 第二行起 6 套：100 巧币
}
```

- 判定口径：`price > 0 && 未解锁` 才算锁着。**不带 price = 免费**，以后要收费只加一个字段。
- 解锁记录**不进单份存档**，统一放全局键 `tangram_shop_v1`：

```json
{ "pstyle": ["neon"], "bgfx": ["stars"] }
```

四巧板 / 七巧板共用这一份 —— 在一边买了，另一边不会再收一次钱（沿用 v0.31 视觉设置 / v0.34 钱包 / v0.36 在线状态的「全局键」套路）。

## 2. 交互：一次误触不能花掉三天的巧币

点卡片分两条路：

| 卡片状态 | 点击结果 |
| --- | --- |
| 免费 / 已买过 | 直接应用（和旧版一样，带 toast） |
| 带价签（未解锁） | 进「解锁皮肤」确认页（`state.overlay='buy'`），**不扣币、不切换** |

确认页把三件事摆在一起：**长什么样（放大预览）· 多少钱 · 现在有多少**；
- 巧币够：「立即解锁」→ 扣币 → 写入全局解锁表 → 立即应用 → 回到面板；
- 巧币不够：按钮置灰显示「巧币不足」，点它弹「巧币不足，还需 N 巧币」，**不解锁也不扣币**，留在确认页；
- 「再想想」= 退出确认页（这一页没有再放底部 X，避免和两个按钮抢位置）。

面板上的呈现：

- 锁定项：卡片右上角金色价签（小金币 + `100` / `150`），字号 21 加粗；
- 已解锁：价签消失，选中时同一位置换回对勾（两者不会同时出现）；
- 板件页底部补一行「带价签的板件需花巧币解锁 · 买一次四巧 / 七巧都能用」。

## 3. 老存档不倒退

升级前的玩家可能正在用「霓虹 / 星夜流萤」这类付费项。`seedShop()` 在 `loadSave()` 末尾把**当前已选中的付费项**就地记为已购 —— 他本来就在用，更新完突然被锁在门外、还要再付一遍钱是明显的体验倒退。

只补「正在用」的那一项，未选中的一概不送。

## 4. 在线奖励：汉字换图标

旧版每档写「体力 +6　巧币 +5　查找道具 +1」，三种货币各占 4~6 个汉字宽，一行的长度随档位跳来跳去；玩家又已经在 HUD / 工具栏里见过这三个图标。改成「图标 + 数字」：

```
⚡+6   🪙+5        （1 分钟档）
⚡+6   🪙+5   💡+1  （60 分钟档）
```

- 图标复用 `drawIcon('energy' | 'coin' | 'hint')`，全部是彩色徽章，深色皮肤下也不用换色；
- 图标 0.78 缩放（约 24px），数字 22px，图标与数字间距 4px，组间距 26px；
- 已领取的档位整体转灰（`COL.textSub`），未领取是金色；
- 底部说明行同样去掉「查找道具」四个字，改成「💡 ×N · 关卡「提示」面板可直接使用」。
