## 二、背景 / 板件 / 音效扩充（需求 1）

### 2.1 背景特效 6 → 10 套
- 原有：暖木微光、流光溢彩、星夜流萤、泡泡漂浮、花瓣飘落、几何轻舞
- **新增**：初雪纷飞（冷色描边白点，浅底也清晰）、烟雨绵绵（斜雨丝）、萤火之森（深青夜空 + 黄绿萤火）、星云流转（深紫夜空 + 彩色星云团）
- **粒子整体加浓**：极光色带 α 0.20→0.42、星空 64→92 颗、泡泡 24→32、花瓣 20→28、几何 15→22；大星十字光芒加长加亮，流萤间隔 4800→3200ms
- **深色夜空**：`stars / firefly / nebula` 三套带 `dark:true`，`drawFxDarkBase()` 铺深蓝 / 深青 / 深紫渐变底；`refreshPalette()` 同步叠加 `DARK_PAL` 暗色板（文字转浅、卡片转深），保证对比度

### 2.2 背景进入关卡 / 对局页
- `renderLevels()` 调 `drawFxLayer(..., 0.55)`、`renderPlay()` 调 `drawFxLayer(..., 0.45)`，强度收敛不抢拼图注意力
- 画在底图之上、卡片 / 板件之下，不写热区、不吞点击
- 修正：深色特效下卡纸仍是浅色纸纹，因此「关号 / 教学提示 / 跳过教学」固定用深色墨（`inkOnCard()`），避免白字白底

### 2.3 板件样式 5 → 9 套
- 原有：经典、糖果、原木、霓虹、马卡龙
- **新增**：水晶（棱面高光 + 折线）、金属（多档拉丝反光）、玉石（云纹 + 边缘内阴影）、荧光（亮底柔光描边）
- 只改绘制，不动几何 / 判定 / 热区（`drawPolyPiece` 的 `path()`/`bbox` 逻辑保持原样）

### 2.4 音效风格 4 → 8 套
- 原有：木质、铃铛、水滴、复古
- **新增**：风铃（空灵悠长）、木琴（圆润弹跳）、泡泡（轻快啵啵）、合成器（sawtooth 未来电子）
- 两端 `game.js` 的 `buildSfxSynth()` 本身就是读 `SFX_STYLES` 配置生成，新风格自动生效，无需改音频层代码

### 2.5 皮肤面板
- 10 背景 / 9 板件 / 8 音效按 3 列布局会到 4 行，卡片高度改为**按当前页签选项数动态计算**（2 行 720 / 3 行 860 / 4 行 1000），最后一行不再掉出卡片、关闭按钮不被压

- 字体：`'700 78px "STCaiyun","华文彩云","STKaiti","KaiTi",serif'`

## 四、图标重设计（需求 3）

`drawIcon()` 拆成两类：
- **彩色徽章系**（货币 / 道具 / 入口）：金币改三层同心 + 星形压印、体力改蓝色能量珠 + 白闪电、查找道具改为放大镜 + 星芒、排行榜改奖杯、在线奖励 / 礼物改礼盒 + 蝴蝶结、设置齿轮加高光环、邀请改双人 + 心、皮肤改调色盘、生命心加渐变高光
- **线性工具系**（返回 / 旋转 / 翻转 / 关闭 / 分享等）保持原样，不影响操作语义
- 所有图标只用传入 `color` 派生明暗（`shadeHex`/`hexA`），换肤自动跟随

受影响位置：主页左右侧入口图标、巧币 / 体力 HUD、查找道具按钮、结算 / 弹层里的所有图标。

## 六、巧币 / 体力挪到右上角（需求 5）

- `config.LAYOUT.HUD.rightAnchor = true, rightPad = 24`（主页）
- `config.LAYOUT.HUD_MIN.rightAnchor = true, rightPad = 24`（对局页）
- `hudPill()` 与 `playHud()` 按 `DESIGN.w - rightPad` 右对齐定位；对局页倒计时胶囊居中，两者无冲突
- 验收脚本 `verify_v17.js` 同步更新为右上角断言

> **真机提示**：微信小游戏原生胶囊按钮（「···」「○」）位于右上角系统层。若真机上 HUD 被压住，只需把 `config.LAYOUT.HUD.rightPad` 和 `HUD_MIN.rightPad` 调大（如 210）即可整组左移避让，不需改绘制代码。这是用户明确要求的右上角位置，预览端无原生胶囊不受影响。
