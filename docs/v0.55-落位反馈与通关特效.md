# v0.55 · 落位红绿反馈 + 通关彩带 + 拖动丝滑

> 反馈四件事：
> ① 平行四边形和橙色板明显重叠了还显示绿色，应该显示红色（这块放不下）；
> ② 淡绿填充 + 绿色柔光看不出来，红色提示也不明显，要非常醒目；
> ③ 重做通关动画，要像参考视频那样有冲击力的 Canvas 特效；
> ④ 卡纸内拖动僵硬，要更灵活丝滑。

## 一、重叠却显示绿色：阈值太宽

`pieceFit` 只判两件事：整块在剪影内、与其它板的交叠 ≤ **单块面积的 2%**。

问题就出在这个 2%：平行四边形 2u² = 18432 单位²，2% = **368 单位²**，
约等于一条 20×20 的重叠三角 —— 玩家截图里那种「明显压住」正好卡在阈值下面，
于是系统认为「放得下」，给了绿色。

**改法**：`C.JUDGE.pairOverlapTol` 从 0.02 → **0.004**（0.4% ≈ 74 单位²，
8×8 的三角）。只剩接缝级的亚像素接触会漏过。

同时把「为什么放不下」也测出来（`pieceIssue`）：

| 返回值 | 含义 | 视觉 |
|---|---|---|
| `null` | 放得下 | 绿 |
| `'overlap'` | 压到别的板 | 红 + 左右轻抖 |
| `'outside'` | 出了剪影（转错角度 / 探出边） | 红 |

拖动中实时算（`onMove`）、松手后整盘算（`runJudge`），逐块写回 `p.issue`。

## 二、把红绿做成「一眼就懂」

旧的绿是「12% 透明填充 + 3px 半透明边」，在浅色卡纸和深色皮肤上都不明显。现在：

**绿（放得下）**
1. 34%→18% 的绿色底填充（板色仍透出来）；
2. **6px 饱和绿描边 + 26px 外发光**；
3. **2px 白芯线** —— 深色背景下也能看清边界；
4. 拖动时每 620ms **向外扩散一圈脉冲环**（明确「可以松手了」）；
5. 拖动中描边粗细/亮度会呼吸。

**红（放不下）**
1. 34% 红色填充；
2. **6.5px 纯红（#FF2626）描边 + 26px 红色外发光**；
3. 72% 白芯线；
4. 压到别的板时**整块左右抖动 240ms**（纯视觉，坐标不动）。

## 三、通关动画（Canvas）

参考视频的做法：从图形中心炸开一大片彩带，边飞边翻面，同时白光一闪、圆环扩散。

实现（`makeWinFx` / `drawWinFx`，画在所有层之上 —— 彩带会从结算面板上飞过）：

1. **中心白光**：0~620ms，径向渐变，半径 50→410，亮度用 `(1-t)^0.7` 衰减；
2. **两圈扩散环**：错开 80ms，半径 30→330，线宽随扩散变细；
3. **彩带**：**240 片**（低帧率 120），从图形中心 40 单位范围内随机出发，
   径向速度 520~1570 单位/s，整体再叠一个向上的初速；重力 1750；
   每片是 8~19 × 5~12 的小矩形，带自转，**厚度随 cos 收缩**做出「翻面」感；
4. **鲜花动画延后 260ms** 出场 —— 先让彩带炸开，再让花绽放，两段不抢焦点；
5. 运动用解析式 `位置 = 初速×t + ½gt²`，掉帧也不会飘/堆积；
6. `reduceMotion` 时整套跳过。

实测：0.18s 中心白光 + 近处彩带，0.42s 铺满整块卡纸，1.3s 仍在飘落并压在结算面板上。

## 四、拖动丝滑：软吸附

旧版 `snapPiece` 在拖动中**直接把板瞬移到吸附点**，最远 120 单位 —— 手感是
「拽一下就粘住 / 抖一下跳走」。

改成两步：

1. **拖动中软吸附**：先让 `snapPiece` 算出吸附修正量 `d`，再按
   `k = (1 - d/150)³` 只走一部分。
   * 离得远（d≈100）：k≈0.01，几乎完全跟手；
   * 中等（d≈40）：k≈0.29，开始被轻轻拉；
   * 近（d≈10）：k≈0.88，平滑滑入；d→0 时一阶导为 0，不会「啪」地一下。
2. **松手补间**：吸附的残余修正 > 3 单位时，**逻辑坐标立即到位**（判定用），
   视觉上用 90ms 滑过去（`p.drawOff` 只是绘制时加的偏移）。
   注意不能反过来先把坐标留在原处再补间 —— 否则 `runJudge` 会读到半路坐标，
   「明明摆好了却不给过」。
