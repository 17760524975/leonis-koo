## 一、分类按钮（用户反馈「纯图案太丑」）

- 恢复文字：每个入口 = **一个拼片徽章 + 华文彩云「四巧板 / 七巧板」**。
- 字体沿用主页标题的 `HOME_VFX.titleFontFamily`（`STCaiyun / 华文彩云`），保留白色描边提升卡片对比度。
- 四巧板徽章是四色菱形，七巧板徽章是 7 面方形拼图；不再展示关数。
- 卡片玻璃质感、选中金边与勾选、热区 `set_t4 / set_t7` 全部不变。

## 二、音频替换

### 曲目映射

| 场景 | 曲目 | 说明 |
|------|------|------|
| 主页 | `bgm_dawn.mp3` 晨光微语 | 88 BPM，木琴 + 铃琶音 + softpad |
| 关卡列表 | `bgm_starlit.mp3` 星海漫游 | 72 BPM，宽混响星光铃，配合深色背景 |
| 对局 | `bgm_flow.mp3` 巧思时刻（5+1 路） | pad / arp / bass / perc / lead + tension |

旧的 `bgm_lv1~4.mp3` 与 `sfx_win.mp3` 已从包内删除；主包仍小于 4MB（约 2.9MB）。

### 动态混音

- 6 个 `AudioBufferSourceNode` 在**同一 WebAudio 时钟**上 `start(t0)`，避免微信多播放器时钟漂移；每路独立 GainNode 做 280ms 线性淡变。
- 预设与 `audio-lab/试听.html` 一致：`calm / play / tense / win`，总线衰减 `mix.trim=0.42`，软限幅 -7dB / 6:1。
- 状态驱动：`go(home|levels)` → calm；`go(play)` → play；倒计时剩余 <20% → tense；`win()` → win。
- 老场景键 `lv1~lv4` 仍由 `setScene()` 发给旧音频层，新增 `setPage()` / `setMix()` 给新音频层；老桩没有这两个方法时静默跳过，历史验收不破。

### 失败音与胜利音

- 新增 `sfx_fail.wav`（0.26s，低沉短促，比成功音轻，只在真实重叠时触发），木质风格用采样、其它 7 种风格用同款合成兜底。
- 胜利音换成试听通过的 `sfx_win_fanfare.mp3`（2.4s 钟声号角），非木质风格仍走各自合成曲，保持风格一致性。

## 三、工程改动

- `tools/audiokit/build_lab.mjs`：纯 JS 把 WAV 转 48kbps 单声道 MP3，短音效保留 WAV，自动清理旧音频。
- `audio-lab/gen_audio.py`：新增 `build_fail()` 生成失败音样片。
- 两端 `game.js` 手写同步：WebAudio 单曲 / 混音链路、`setPage` / `setMix`、`sfx_fail` 合成兜底、`pkgPath()` 同时兼容音效键与完整文件名。
- `tools/verify_audio.js` 重写为新链路端到端验收（含预设增益、紧张层、前后台、音效实际起播）。

## 四、验收

语法、三端一致性、smoke、全部 verify 通过；`verify_levels`（缺 report）与 `verify_v20`（旧吸附音频谱断言）为改动前已存在的两项失败，与本次无关。
