## 一、游戏解读

### 1. 产品定位
《方寸巧拼》（原名「四巧·七巧」）是一款**微信小游戏 + 网页预览版**双端拼图游戏：
- **四巧板 30 关** + **七巧板 60 关**，共 90 关，分「几何 / 动物 / 人物 / 交通」等章节。
- 核心操作：拖动摆放、拖拽/点手柄旋转（吸附 45°）、双击翻转、顶点/边/网格三层吸附。
- 商业化与留存：倒计时 + 3 心、巧币/体力经济、复活（看广告/巧币）、每日在线奖励 6 档、邀请有礼、查找道具、连胜与三榜（主线/连胜/好友）、皮肤。

### 2. 技术架构（关键：三端同源）
```
js/                  唯一真源（config / geom / judge / levels / core）
  ├─ config.js       所有可调参数与配色（改数值只改这里）
  ├─ geom.js         几何工具与缓动
  ├─ judge.js        栅格覆盖率判定（位掩码，4/7 块通用）
  ├─ levels.js       关卡数据（90 关）
  └─ core.js         渲染 / 交互 / 状态机（约 5400 行）
preview/js/          网页预览端副本（由 tools/sync.js 同步）
miniprogram/         微信小游戏工程（导入这一层，game.js + game.json）
```
- **纯 Canvas 绘制，零图片依赖 UI**，Web Audio 现场合成音乐（主页 8 小节四声部轻音乐 + 4 首真人关卡 mp3，响度已对齐）。
- **约定**：`js/` 是唯一真源，改完必须 `node tools/sync.js` 同步到两端，禁止手改副本。
- 云开发存档 + 真实榜单（`cloud1-d4g6rm6duad5ba0aa`），好友榜走微信开放数据域。
- 主包约 2.96MB（微信硬限制 4MB）。

### 3. 代码质量评价
优点是**参数化做得非常彻底**（策划改数值只动 config）、验收体系完善（十多个 verify 脚本 + 截图 harness）、版本演进有完整规格文档。这是一个工程化程度很高的项目。

## 二、待优化点（按优先级）

### A. 视觉与表现层（本次已处理）
1. **主页背景偏静态**：原实现是 Ken Burns 缓慢平移 + 3 个光斑 + 11 秒扫光，动效过于微弱，用户反馈「太老套、没有动态效果」。→ 本次新增 5 套粒子动态背景。
2. **皮肤系统太单薄**：原来只有 3 套纯配色（warm/mint/night），且注释明说「只换配色，不影响其它」，缺少背景特效、板件样式、音效风格。→ 本次重构为 4 页签皮肤面板。
3. **UI 缺少"活着"的感觉**：标题、按钮、入口都无呼吸/流光/入场动效。→ 本次加入标题描边柔光+呼吸、帆船光晕+星点、按钮流光、入口呼吸波。

### B. 仍建议后续优化（本次未做，供决策）
| 方向 | 建议 | 收益 |
|---|---|---|
| **性能优化** | `drawBg()` 每帧重建多个 `createRadialGradient/createLinearGradient`；中低端机可缓存为离屏 canvas 或降频重绘 | 降低 DrawCall/CPU，提升帧率稳定性 |
| **首屏体验** | 主页 4 张入口卡片信息密度低，可加「今日进度/连续登录」等动态内容 | 提升回访动机 |
| **新手引导** | 教学目前只在第 1 关，复杂关卡（七巧板翻转）缺少渐进式引导 | 降低中期流失 |
| **音频** | 关卡 mp3 固定 4 首轮换，长时间游玩易疲劳；可考虑动态混音/更多曲目 | 提升沉浸感 |
| **无障碍** | 增加色弱友好的板件描边方案、减少动效开关入口前置 | 合规与包容性 |
| **商业化** | 广告位 unitId 目前留空（个人主体无流量主），需开通后填入 config.ADS | 变现闭环 |

### C. 关于"用什么技术优化"的建议
**结论：继续沿用纯 Canvas 2D + 程序化绘制是当前最优选，不建议引入重量级引擎。**
- 理由：项目判定/吸附/关卡数据都基于设计坐标系（750×1624）与 Canvas 手绘，迁移 Cocos 等引擎成本极高且会破坏 90 关验收；包体已接近 3MB，引入引擎会逼近 4MB 主包红线。
- 若追求更进一步的效果，可**渐进式**引入：
  - **离屏 Canvas 缓存**静态背景层（性能）。
  - **WebGL / 着色器**做极光、水面折射（仅在必要时，注意小游戏兼容与包体）。
  - **骨骼/粒子编辑器**（如 DragonBones）做复杂角色动效（本项目风格不需要）。
  - **Lottie**（小程序端）做矢量 UI 动画，需评估小游戏支持度。

## 三、本次升级内容（v0.27）

### 1. 动态背景系统（`core.js` + `config.js`）
- 新增 `C.BG_FX`（6 套，含原版 classic）与 `C.BG_FX_PARTS`（粒子参数）。
- 新增粒子引擎：`buildFxParts()` 惰性生成、`drawFxLayer()` 统一绘制、`hexA()/petalPath()` 等工具。
- 5 套新特效：**流光溢彩 aurora / 星夜流萤 stars / 泡泡漂浮 bubbles / 花瓣飘落 petals / 几何轻舞 geometric**。
- 性能约束：低帧率（lowFps）粒子减半、`reduceMotion` 全停、粒子按当前皮肤主色着色、换肤/换特效时重建缓存。

### 2. 主页 UI 增强（`renderHome()`）
- 标题：`strokeText` 描边 + 金色柔光 + 轻微缩放呼吸。
- 帆船：径向光晕 + 10 颗环绕星点（随相位呼吸）。
- 开始按钮：周期流光扫过（clip 在圆角内，不挡文字）。
- 入口卡片：按 y 位置错相的呼吸光晕，形成自上而下点亮波。

### 3. 板件样式（`drawPolyPiece()`）
- 新增 `C.PIECE_STYLES` 5 种：**经典 / 糖果渐变 / 原木纹理 / 霓虹发光 / 马卡龙**。
- 只改填充/描边质感，**不动几何、判定、热区**（`path()` 与 bbox 逻辑保持不变），零回归。

### 4. 皮肤面板重构（`renderSkin()`）
- 从单页配色网格改为 **4 页签**：配色 / 背景 / 板件 / 音效。
- 配色新增「落日 / 海岸」两套（共 5 套）。
- 每类选项含静态预览图，选中态金色描边 + 右上角对勾。
- 三类风格（bgFx / pieceStyle / sfxStyle）+ 配色（skin）**独立存储、任意组合**。

### 5. 音效风格（`game.js` 两端 + `config.js`）
- 新增 `C.SFX_STYLES`（木质 / 铃铛 / 水滴 / 复古）。
- 两端 `game.js` 新增 `setSfxStyle()`：按 pitch/decay/wave/bell 参数重建 tap/pick/snap 合成音；**非木质风格强制走合成**（绕过固定木质 wav），通关曲保持原样。
- `core.js` 切风格时调用接口 + `play('sfx_pick')` 即时试听。

### 6. 存档兼容
- `defaultSave()/loadSave()` 新增 3 字段并做老存档兜底与非法值收敛，老玩家升级无感。
