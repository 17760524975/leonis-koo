## 2. 控制台三步

### 2.1 建集合

云开发控制台 → **数据库** → 新建集合，建两个：

| 集合 | 存什么 | 文档结构 |
|---|---|---|
| `players` | 每人一行：昵称 / 头像 / 星星数 / 通关数 / 最高连胜 | `{ _id, openid, nick, avatar, src, auth, stars, cleared, streak, streakV, updatedAt }` |
| `saves` | 每人一行云端存档（四巧 + 七巧两套快照） | `{ _id: openid, openid, nick, sets, updatedAt }` |

### 2.2 集合权限（关键）

两个集合都选 **「所有用户不可读写」**（仅云函数可访问）。

理由：客户端从来不直连数据库，读写全部走云函数 `player`（管理员身份）。
选「仅创建者可读写」看似更宽松，但本项目文档是云函数写入的、没有 `_openid` 字段，
creator 规则根本匹配不到——一旦以后有人加了客户端直读，就会出现「明明是我的数据却读不到」的怪问题。
直接用「所有用户不可读写」最省心，也不会被改包伪造成绩。

> 如果你以后要做「所有用户可读」的公开榜单集合，再单独建一个 `ranks` 并设「所有用户可读，仅创建者可写」，
> 不要把 `players` 放开。

### 2.3 用户隐私保护指引（v0.14 新增，不做拿不到昵称头像）

公众平台 → 设置 → 服务内容声明 → **用户隐私保护指引** → 去完善 → 增加信息类型 →
勾选 **「昵称、头像」** → 确认。

不做这一步的后果：`wx.createUserInfoButton` 直接报
`fail please use go to mp open official popup or use wx.onNeedPrivacyAuthorization to announce your privacy`，
玩家点授权按钮也没反应，只能自己起昵称。

> 代码里已经调了 `wx.requirePrivacyAuthorize`（基础库 2.32.3+），首次会弹微信官方隐私弹窗；
> 但"声明了哪些信息类型"必须在后台勾，前端声明不了。

### 2.3.1 好友榜（开放数据域，不需要控制台配置）

好友榜读的是**微信关系链云存储**，不是云开发数据库，所以：

- 不需要建集合、不需要改权限；
- 代码侧已就绪：`miniprogram/openDataContext/` + `game.json` 的 `openDataContext` 字段 +
  `js/friendrank.js`（主域桥）；
- 但**必须真机验证**：开发者工具/浏览器没有好友关系链，模拟器通常返回空列表。

> 数据流：主域 `wx.setUserCloudStorage({key:'tangram'})` → 好友各自写一份 →
> 开放数据域 `wx.getFriendCloudStorage({keyList:['tangram']})` 读出来画到 `sharedCanvas`。
> 与 `players` 集合是两套数据，互不影响。

### 2.4 部署云函数

微信开发者工具 → 资源管理器右键 `cloudfunctions/player` → **上传并部署：云端安装依赖**（不是「所有文件」）。
依赖只有 `wx-server-sdk ~2.6.3`，云端安装约 20–60 秒。

部署成功标志：云开发控制台 → 云函数 → 看到 `player`，版本号 ≥ 1，调用次数开始增长。

> **v0.18 必须重新部署一次**：新增 `streakV` 口径迁移（老数据的「当前连胜」首次上行时
> 按新口径覆盖一次）。不部署的话，旧版刷出来的虚高连胜会被 `Math.max` 永久钉在连胜榜上。

### 2.5 本地调试（可选）

开发者工具里第一次调用云函数前，确认：
- 工具栏「云开发」已选到 `cloud1-d4g6rm6duad5ba0aa`
- 详情 → 本地设置 → 增强编译 已勾选（`wx.cloud` 需要）

## 4. 常见错误码对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `云环境 ID 不对` | envId 写错 / 环境不属当前小程序 | 核对 `cloud1-d4g6rm6duad5ba0aa`，确认是「公众平台登录」下看到的环境 |
| `云函数未部署` | 只上传了文件、没部署，或函数名不是 `player` | 右键 →「上传并部署：云端安装依赖」 |
| `数据库集合未创建` | `players` / `saves` 没建 | 控制台建集合，名字区分大小写 |
| `集合权限不放行` | 集合权限设置拦了云函数 | 云函数用管理员身份，正常不会被拦；检查是否误配了安全规则 |
| `拿不到 openid` | 在浏览器/开发者工具「游客模式」里调用 | 用真机预览或已登录的开发者工具 |
| `please use go to mp open official popup…` | 没配《用户隐私保护指引》 | 见 2.3，勾选「昵称、头像」后重新预览 |
| 昵称一直显示「巧手XXXX」 | 玩家没点授权按钮 / 客户端只给了匿名资料 | 正常降级；引导玩家点设置页的「使用微信昵称头像」 |
| 头像是首字不是微信头像 | 头像图没加载出来（域名/网络） | 开发设置 → downloadFile 合法域名加 `thirdwx.qlogo.cn` |

## 6. 为什么音频没有走云存储

5 首 BGM 压到 90s / 48kbps / 单声道后合计 **2.52MB**，主包 3.31MB（上限 4MB），
直接打进包里最稳：断网能听、首屏不用等下载、不消耗云存储流量。

如果以后要放整首歌（原始 5 首共 34MB），再改走云存储 + CDN：
上传到「存储」→ 拿 https 地址 → 把 `AUDIO.bgm` 换成 URL 即可，
`InnerAudioContext` 支持网络地址，代码不用改结构。
