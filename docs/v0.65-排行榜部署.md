## 2. 建 `starEvents` 集合

云开发控制台 → 数据库 → 新建集合，名字必须**逐字**为 `starEvents`（大小写敏感，云函数里 `const SEVENTS = 'starEvents'`）。

文档结构（云函数自己写，只说明字段含义）：

```js
{
  _id: "openid|uid|rev|day",   // 主键 = 去重键，唯一即天然幂等，不用另跑去重任务
  openid: "oXXXX",             // 谁上报的（getWXContext 取，客户端伪造不了）
  uid: "t7-injected",          // 是「哪一份关卡」而不是「第几关」——插队不影响归属
  rev: 1,                      // 关卡版本号，关卡重做后 rev 变，新旧成绩自然分开
  day: "2026-11-26",           // UTC+8 的自然日，只认当天
  stars: 3,                    // 本次星级 1~3
  weekKey: "2026-W48",         // UTC+8 的 ISO 周
  ts: 1732600000000
}
```

**权限**：选「所有用户不可读写」。理由同 `players` / `saves` —— 客户端只走云函数（管理员身份），
集合不对外暴露就不用应付 `_openid` 注入。

**索引**（可选，量大再加）：`weekKey`（升序）单字段索引即可，用于按月清理历史事件。
`_id` 自带唯一索引，幂等靠它，不需要额外建唯一索引。

**清理**：这张表只用来去重，过期的（`weekKey` 不是本周且超过 4 周）可以删。云开发控制台
「数据库 → 高级操作」里跑一次性删除即可：

```js
// 删 2026-W40 及之前的去重记录（示例，按需改周键）
db.collection('starEvents').where({ weekKey: _.lt('2026-W41') }).remove()
```

不清理也不会错，只是占空间（每个登录用户每周最多 3 关 × 7 天的量级）。

## 4. 自检（不用装小游戏包）

控制台 → 云函数 → `player` → 测试，依次发：

```js
// ① 看本周榜：应该返回 list + me + nextResetAt + weekKey + totalPlayers
{ "action": "rank", "tab": 2 }

// ② 看全服榜：字段同上，但主值是 stars
{ "action": "rank", "tab": 0 }

// ③ 好友榜：不查库，只回一个标记（真数据在开放数据域里画）
{ "action": "rank", "tab": 1 }      // → { note: 'friend', nextResetAt, weekKey }
```

判定标准：

- `nextResetAt` 是**北京时间下周一 00:00** 的毫秒（用 `new Date(nextResetAt)` 看，应该落在周一 00:00:00）。
- `weekKey` 形如 `2026-W48`，与当天所在周一致（UTC+8，不是 UTC）。
- 发一次带 `weekEvents` 的 `sync` 后，`starEvents` 里应出现 `openid|uid|rev|day` 格式的 `_id` 记录；
  **同一个事件再发一次，`weekStars` 不应该再涨**（幂等，返回 `delta: 0`）。

## 5. 兼容与回滚

- **旧包（< v0.65）打新云函数**：完全可用。旧包 `sync` 不带 `weekEvents` → 本周星恒 0；
  旧包 `rank` 只请求 0/2 两个 tab，其中 tab 2 现在返回本周榜 —— 旧包的好友榜本来走开放数据域、
  不读云端返回，所以不会串位。
- **新包（v0.65）打老云函数**：会出现页签错位（tab 1/2 语义反了）。所以**先发云函数**。
- **回滚**：把 `miniprogram/js/cloud.js` 的 `rank` 调用参数改回旧映射即可（`tab 1 → 2`）；
  `starEvents` 留着不写不读，不影响主流程；开放数据域用 `keyList: [tangram_v2, tangram]` 同时读两个键，
  回滚到只写 `tangram` 的旧版也不会丢好友。

## 6. 防刷边界（已实现，部署后确认）

| 限制 | 位置 | 说明 |
|---|---|---|
| `stars ≤ 300`、`cleared ≤ 120` | `sync` 夹取 | 93 关 × 3 星 + 余量，超了直接夹，不报错 |
| 单条周星 `stars ∈ [1,3]` | `applyWeekEvent` | 别的值整条拒收 |
| 只认当天事件 | `applyWeekEvent` | `day !== 今天(UTC+8)` 拒收，补刷历史拿不到分 |
| 单日周星增量 ≤ 60 | `sync` | 60 = 20 关 × 3 星，正常玩家一天打不到这么多 |
| `openid` 只信 `getWXContext()` | 全局 | 客户端传什么都不认 |
| `sets` ≤ 200KB | `sync` | 防止把存档当网盘 |
