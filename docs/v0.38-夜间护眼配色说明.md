# v0.38 · 夜间护眼配色 + 主页按钮换序

> 两个需求来自同一轮反馈：
> ① 皮肤面板里「落日 / 海岸」两套配色下线，换成一款深色的、用于夜晚护眼的配色；
> ② 主页把「开始游戏」挪到两套关卡入口下面，并把关卡入口卡片缩小一点。

---

## 一、皮肤面板

### 1. 分类文字回到胶囊中线

四个页签（配色 / 背景 / 板件 / 音效）原本按 `text(tabY + 9)` 绘制。胶囊纵向范围是 `tabY ± 34`、中线正好在 `tabY`，而 `text()` 用的是 `textBaseline='middle'`，那个 `+9` 等于把文字整体压低 9px，看起来"上紧下松"。

现在改成 `tabY + 1`（只保留 1px 光学补偿）。`tools/verify_v038.js` 第 4 节会取渲染帧里「配色」二字的实际 y 与热区中线比较，偏差需 ≤ 3px。

### 2. 「落日 / 海岸」→「夜间护眼」

| 项 | 内容 |
|---|---|
| 键名 | `SKINS.dusk` |
| 名称 | 夜间护眼 |
| 标记 | `dark: true`（深色皮肤） |
| 底色 | `bg #1E2530` / `bgDeep #171D26` / `bgTop #28313F`（暖石墨灰，少蓝光） |
| 文字 | `text #E8EDF4` / `textSub #A9B4C4` |
| 主色 | `gold #E9B16A` / `goldDeep #D99A4E` / `goldEdge #BE7F35`（柔和琥珀，替代纯白高亮） |
| 卡片 | `card rgba(42,50,63,0.96)` / `board rgba(34,42,55,0.94)` |

`refreshPalette()` 重写为三段：

1. **浅色基准复位** —— 先把 `COLORS` 里那份浅色基准全量写回 `COL`；
2. **深色打底** —— 深色皮肤先铺一遍 `DARK_PAL`，保证 `cardEdge / board / targetFill / targetEdge / targetSilhouette / splitLine / track / starOff / slotBg / mask / snapRing / shadow / shadowPiece` 这些"只出现在深色板里"的字段也齐全；
3. **皮肤覆盖** —— 再用皮肤自己的字段覆盖成更暖、对比更低的夜间色。

同时修掉一个老问题：以前只做「皮肤 → 深色板」两步、从不复位，所以从深色特效切回浅色时 `board / targetEdge / mask` 会残留深色（表现为托盘、目标轮廓还是暗的）。第 1 步的基准复位把这个坑填了。

老存档兼容：`state.save.skin` 若是已下线的 `sunset / ocean`，读档时静默回落 `warm`，面板不会出现"一个都不高亮"。

### 3. 深色下的整页适配

深色皮肤不是只换几个字段就够了，几处"默认浅色"的地方单独处理：

| 位置 | 处理 |
|---|---|
| 主页底图 | 深色皮肤**不铺**米色桌面照片（一张浅色照片靠色罩压暗只会得到脏灰），直接走渐变夜景 |
| 主页左上柔光 | `rgba(255,255,255,0.85)` → `0.10`，否则深底上糊出一大块白斑 |
| 主页光斑 / 扫光带 | 光斑减半、白光带 `0.12` → `0.05` |
| 对局卡纸 | 不铺 `board_paper` 浅色纸纹，改填 `COL.board` 深色纸面 + 极淡白纹 |
| 卡纸上的字 | `inkOnCard()` 在深色皮肤下返回浅墨（关名 / 教学提示 / 跳过教学） |
| 教学提示条 | 白底 `rgba(255,255,255,0.82)` → 深底 `rgba(12,18,28,0.72)` |
| 巧币 / 体力胶囊 | `pillFillDark rgba(10,14,22,0.58)`（比背景更暗一档，白字才压得住） |
| 主页入口卡片 | 深色渐变 + 浅墨汉字 + 半透明浅描边 |
| 对局工具栏 / 返回键 | 新增 `TOOL_TONE_DARK`：同色系深色糖 + 提亮 accent 图标，避免奶白按钮在深色页里最亮 |

深色特效（星星 / 星云）那条老路径**没有改**：纸面仍是浅色纸纹，`inkOnCard()` 也只认"深色皮肤"，所以星星背景下的深墨字照旧正确。

## 二、主页按钮换序

### 顺序

```
四巧板  (set4Y)
七巧板  (set7Y)
开始    (startY)
星数    (starY)
```

`homeLayout()` 从「开始 → 四巧 → 七巧 → 星数」改成：

```js
var startY = starY - 86;
var set7Y = startY - (HL.startGap || 126);   // 按钮半高 54 + 净空
var set4Y = set7Y - (HL.setGap || 118);      // 卡片高 100 + 净空
```

星数行仍锚在安全区上方，整组按钮吃掉细长屏多出来的高度，布局逻辑不变。

### 卡片缩小

| 项 | v0.37 | v0.38 |
|---|---|---|
| 卡片 | 440×112 | **408×100** |
| 圆角 | 26 | 24 |
| 徽章 | 64 @ x−146 | 58 @ x−134 |
| 文字 | 42px @ x−80 | 38px @ x−76 |
| 选中灯 | x+w/2−56 | x+w/2−52 |

热区随卡片一起缩，仍高于 `MIN_HIT=88`。

## 三、验收

新增 `tools/verify_v038.js`（27 项），覆盖：

- 配色表只剩 4 套、`sunset / ocean` 下线、`dusk.dark === true`、深色字段无缺项；
- 切 dusk 生效（bg / card / board / targetEdge），切回 warm 后深色字段按亮度复位；
- 老存档 `skin='sunset'` 回落 `warm`；
- 四个页签文字与胶囊中线偏差 ≤ 3px；
- 主页顺序 四巧 → 七巧 → 开始 → 星数，间距 118 / 126，热区中心与布局一致，卡片 408×100；
- 深色皮肤下卡纸上的三处文字（关名 / 教学提示 / 跳过教学）都是浅墨；
- 三端 `core.js` / `config.js` 逐字节一致。

顺带修了几处**早于本版就已失效**的验收脚本（上游把版本号写成 `v0.31` 起就不再同步）：

- `verify_v06 / v07 / v14 / v15 / v18 / v19`：版本号正则上界只到 `v0.29`，改成与 v0.16+ 脚本一致的 `/^v0\.\d+(\.\d+)?$/`；
- `verify_v06`：点击「七巧板 / 四巧板 / 开始」用的是 `CFG.LAYOUT.HOME` 的静态值，底部锚定后早就点空，改读运行时 `homeLayout()`；
- `verify_v31`：布局顺序断言由「开始 → 四巧 → 七巧」改为新顺序，并补上卡片尺寸与夜间护眼配色两项。

全量 31 个 smoke / verify 脚本当前全部通过。
