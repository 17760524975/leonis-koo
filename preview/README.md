# 方寸巧拼 · 网页预览版

> 纯静态、零外部依赖、整个文件夹拷走就能跑。点开就能玩一局，不需要装任何东西。

## 电脑上怎么打开

双击 `index.html`。Chrome / Edge / Safari 都行。

> `file://` 下浏览器会禁掉 `fetch`，所以背景音乐与音效走 `<audio>` 元素播（能出声，只是吸附音比走 Web Audio 多几毫秒延迟）。

## 手机上怎么打开（**不要**直接双击 html）

手机浏览器打不开电脑上的 `file://` 文件，必须用 http 访问。两种方式：

### A. 电脑起一个本地服务，手机连同一个 Wi-Fi（最快）

在**这个文件夹**里执行：

```bash
# 有 Python 的机器
python -m http.server 8080
# 或者有 Node 的机器
npx serve -l 8080 .
```

然后手机浏览器打开（本机当前局域网 IP 为 `192.168.0.138`，你的机器可能不同，用 `ipconfig` 查 IPv4）：

```
http://192.168.0.138:8080
```

> iPhone 用 Safari 打开；安卓用 Chrome / 系统浏览器。手机和电脑必须在同一个 Wi-Fi 下，电脑防火墙要放行 8080 端口。

### B. 丢到任意静态托管

把整个 `preview/` 目录上传到任意静态站点（对象存储、GitHub Pages、内网 nginx 都行），手机打开对应地址即可。

## 手机上的操作

- 手指按住托盘里的板拖到拼图区中间的目标轮廓里，四块拼满即通关（不设失败）
- 工具栏从左到右：逆时针转 90° / 顺时针转 90° / 翻转 / 提示（每关 1 次）/ 重来
- 顶点靠近目标顶点会自动吸附（吸附时白色高亮环 + 轻微震动）
- 关掉音乐后进度会保留，不会从头播

## 已验证

- 断网刷新：完全正常（无 CDN、无外部字体、无远程请求）
- 拷贝到其它路径后双击：正常（全部相对路径，素材都在本目录内）
- 资源网络面板：图片 / 音频全部 200，无 404
- 移动视口：375 / 390 / 414 / 320 宽均无横向滚动、无内容溢出
- 首帧不依赖音频解锁：静音也能正常玩，第一次点击后才出声

## 目录

```
preview/
├── index.html          # 入口，双击这个
├── css/style.css       # 全屏、禁滚动、禁缩放、安全区探针
├── js/
│   ├── config.js       # 所有可调参数与配色（策划改数值只改这里）
│   ├── geom.js         # 纯几何
│   ├── judge.js        # 覆盖率 / 溢出 / 重叠判定
│   ├── levels.js       # 6 关数据（求解器离线生成，勿手改）
│   ├── core.js         # 页面状态机 + Canvas 渲染 + 输入
│   └── game.js         # 浏览器适配层（Canvas / 触摸 / 存档 / 音频）
└── assets/
    ├── img/            # home_bg_desk.png  board_paper.png
    └── audio/          # bgm_main.mp3  sfx_*.wav/mp3
```

`js/` 下前 5 个文件与微信小游戏包共用同一份源码（`tools/sync.js` 同步），改逻辑请改 `tangram/js/` 再同步，不要在这里改。
